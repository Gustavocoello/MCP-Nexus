## CRITICAL RULES

1. **ORM Standard**: Always use SQLAlchemy 2.0 syntax (e.g., `select()`, `session.execute().scalar_one_or_none()`). Do not use raw SQL unless strictly necessary.
2. **Destructive Commands**: NEVER execute `DROP TABLE` or `DELETE FROM` without explicit human confirmation.
3. **Session Management**: Always wrap database sessions in a `try/except/finally` block to ensure `db_session.close()` is called.

## Migration Workflow (Alembic)
