## CRITICAL RULES

1. **Protocol Compliance**: All servers must strictly adhere to the MCP specification (JSON-RPC).
2. **Tool Registration**: Every new tool added to an MCP server must include a clear, descriptive `description` string, as the LLM uses this to understand when to invoke it.
3. **Error Handling**: MCP servers should never crash silently. Catch exceptions and return them as formatted MCP Error Responses so the agent knows what went wrong.
